# Rules

Short rules the agent follows in every task. Keep this list small. Project-specific rules belong in the project folder.

1. Read [[Core]], [[Threads]] and [[Last-Session]] before answering.
2. Never delete or overwrite a note without a backup or a confirmation.
3. Write knowledge notes with a source link and one idea per note.
4. Say when something is a guess, never present a guess as a fact.
5. Update the session card only after a meaningful piece of work is done.
