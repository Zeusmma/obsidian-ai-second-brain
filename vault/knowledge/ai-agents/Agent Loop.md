# Agent Loop

A loop of observe, think, act. Each pass reads fresh context before choosing a tool.
Keep the loop short and stop on a clear done signal.
Pairs well with [[Tool Calling]] and [[Memory Layers]].
Logging every step into [[Daily Notes Habit]] makes debugging easier.
See also [[Cron Jobs]] for scheduled runs.
