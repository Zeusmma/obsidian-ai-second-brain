# Evaluation Basics

Write five to ten fixed test cases before changing a prompt.
Score with a simple pass or fail, then track the count over time.
Pytest works fine for this: [[Testing with Pytest]].
A failing case becomes a new rule in [[🔮 Companion/Rules|Rules]] or a [[Guardrails]] check.
