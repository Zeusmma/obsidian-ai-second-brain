# Memory Layers

Three layers work well: a tiny always-loaded profile, a rolling session card, and a searchable knowledge store.
The profile lives in [[Core]], the session card in [[Last-Session]].
Long-term facts become source-linked notes such as [[Atomic Notes Method]].
Review stale items during the [[Weekly Review]].
