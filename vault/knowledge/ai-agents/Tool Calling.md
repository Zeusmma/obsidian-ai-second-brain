# Tool Calling

A tool is a named function with a typed input and a short description.
Prefer few, well-named tools over many vague ones.
Validate arguments before running, as in [[Type Hints]].
Webhooks ([[Webhooks]]) can trigger the same tools from outside.
Related: [[Guardrails]], [[Agent Loop]].
