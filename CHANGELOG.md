# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-25

### Added
- Demo vault layout with Companion notes, knowledge lobes, projects, maps, templates and daily notes (all fictional).
- Six CSS snippets: cosmic graph, readable notes and a calm interface.
- Neural System plugin with 18 interactive views and Brain Signal plugin.
- `scripts/install-into-vault.sh` to add the theme and plugins to an existing vault without overwriting files (backups of the JSON settings, `--force` to overwrite).
- `AI_SETUP.md` prompt and checklist for AI-assisted installation.
- 20 screenshots and a hero collage; CI workflow with plugin syntax checks and a dry install.
- CONTRIBUTING, SECURITY, issue templates and `.editorconfig`.
